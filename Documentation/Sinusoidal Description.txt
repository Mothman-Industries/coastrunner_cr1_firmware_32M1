A sine table of 256 8 bit values with 3rd harmonic injection over 90* will be generated (2^8)

PID will generate a 8 bit value (2^8) using a PLL

The PSC counter will count up to 255 (2^8)

The sine value will be selected and multiplied with the PID error 

Result is divided by 256 for scaling (bitshift right by 8)

The scaled value is continuously compared to the PSC counter

A software PLL will be generated and compared to the edges of the hall sensors, giving 6 events per rotation.

The software PLL frequency is chosen from the target speed measured by the ADC from the controller
    This may enable putting the ADC in free-running mode, but that might prevent current sensing

Timer 1 will be repurposed to generate the sine wave rather than measure the RPM
